プライバシーポリシー

OPPO Hub（以下「本アプリ」）は、開発者本人だけが自分のために使う個人用ツールです。第三者へのサービス提供は行っていません。

1. 取得する情報

本アプリは、利用者本人が許可した範囲で、次の情報を取得します。

  • Google ドライブ：ファイルのメタ情報（ファイル名、種類、更新日時、更新者の表示名、リンク）。ファイルの中身は取得しません。
  • Google ドライブ：本アプリ自身が作成したファイル（資料・バックアップ）。
  • GitHub・Discord：利用者本人のリポジトリの更新情報、および本人が指定したチャンネルへの本人の投稿。

2. 利用目的

取得した情報は、利用者本人のタスク管理（更新の通知、要約、タスクへの整理）にのみ使います。広告、販売、第三者への提供には一切使いません。

3. 保存場所

情報は利用者本人が管理する端末（スマートフォン）上のデータベースに保存します。バックアップを利用者本人の Google ドライブに保存する場合は、暗号化したうえで保存します。

4. 外部サービスへの送信

整理のために、更新情報の一部（タイトル、種類、利用者本人の投稿の本文など）を文章生成 AI の API（Google Gemini）へ送信することがあります。ファイルの中身は送信しません。

5. Google API から取得したデータの扱い

本アプリによる Google API から取得した情報の利用と他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

6. 削除

利用者本人は、端末上のデータベースと Google ドライブ上のファイルをいつでも削除できます。Google アカウントの設定から、本アプリへのアクセス権をいつでも取り消せます。

7. 改定

内容を変更した場合は、このページを更新します。
